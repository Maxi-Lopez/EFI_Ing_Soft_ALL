## 5. Modelos — `src/productos/models.py`

```python
from django.db import models


class Proveedor(models.Model):
    nombre = models.CharField(max_length=150)
    telefono = models.CharField(max_length=150)
    activo = models.BooleanField(default=True)

    def __str__(self):
        return f"Proveedor {self.nombre}, estyo activo: {self.activo} ."


class Articulo(models.Model):
    nombre = models.CharField(max_length=150)
    precio = models.DecimalField(max_digits=10, decimal_places=2)
    stock = models.IntegerField()
    proveedor = models.ForeignKey(
        Proveedor,
        on_delete=models.CASCADE,
        related_name="articulos",
    )
    timestamp = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.nombre
```

**Relación:** `Proveedor` 1 → N `Articulo` (FK con `related_name="articulos"`).

| `0002_proveedor` | Crea `Proveedor` |
| `0003_articulo_proveedor` | Agrega FK `proveedor` a `Articulo` |

## 6. Serializers — `src/productos/serializers.py`

```python
from rest_framework import serializers
from .models import Articulo, Proveedor


class ProveedorSerializer(serializers.ModelSerializer):
    class Meta:
        model = Proveedor
        fields = "__all__"
        read_only_fields = ['id']


class ArticuloPublicSerializer(serializers.ModelSerializer):
    proveedor = ProveedorSerializer(read_only=True)

    class Meta:
        model = Articulo
        fields = [
            'id',
            'nombre',
            'precio',
            'stock',
            'proveedor',
            'timestamp',
        ]
        read_only_fields = ['id', 'timestamp']


class ArticuloSerializer(serializers.ModelSerializer):
    class Meta:
        model = Articulo
        fields = [
            'id',
            'nombre',
            'precio',
            'stock',
            'proveedor',
            'timestamp',
        ]
        read_only_fields = ['id', 'timestamp']
```

**Patrón:** se usa un serializer *público* (anidado, solo lectura del proveedor) para
lecturas y un serializer *plano* (acepta `proveedor_id`) para escrituras.

### 7.2 Vistas web / genéricas — `src/productos/views.py`

```python
from rest_framework import generics, status
from rest_framework.decorators import api_view
from rest_framework.permissions import IsAuthenticatedOrReadOnly
from rest_framework.response import Response

from .models import Articulo, Proveedor
from .serializers import (
    ArticuloSerializer,
    ProveedorSerializer,
    ArticuloPublicSerializer,
)


class ArticuloListCreateAPIView(generics.ListCreateAPIView):
    queryset = Articulo.objects.all().select_related("proveedor")
    serializer_class = ArticuloSerializer
    permission_classes = [IsAuthenticatedOrReadOnly]

    def get_serializer_class(self):
        if self.request.method == 'GET':
            return ArticuloPublicSerializer

        return ArticuloSerializer


class ArticuloDetailGenericAPIView(generics.RetrieveUpdateDestroyAPIView):
    queryset = Articulo.objects.all().select_related("proveedor")
    serializer_class = ArticuloSerializer
    permission_classes = [IsAuthenticatedOrReadOnly]


class VerArticulos(generics.ListAPIView):
    queryset = Articulo.objects.all().select_related("proveedor")
    serializer_class = ArticuloPublicSerializer
    permission_classes = [IsAuthenticatedOrReadOnly]


class BorrarArticulo(generics.DestroyAPIView):
    queryset = Articulo.objects.all()
    serializer_class = ArticuloSerializer
    permission_classes = [IsAuthenticatedOrReadOnly]


@api_view(['GET', 'POST'])
def proveedor(request):
    if request.method == 'GET':
        proveedores = Proveedor.objects.all()
        serializer = ProveedorSerializer(proveedores, many=True)

        return Response(
            serializer.data,
            status=status.HTTP_200_OK
        )

    if request.method == 'POST':
        serializer = ProveedorSerializer(data=request.data)

        if serializer.is_valid():
            serializer.save()

            return Response(
                {"mensaje": "Proveedor creado", "data": serializer.data},
                status=status.HTTP_201_CREATED
            )

        return Response(
            serializer.errors,
            status=status.HTTP_400_BAD_REQUEST
        )
```

**Patrón de respuesta de creación/errores:**

```python
# Éxito
return Response({"mensaje": "...", "data": serializer.data}, status=status.HTTP_201_CREATED)
# Error de validación
return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

### Rutas finales expuestas (prefijo `/api/`)

| Método | Ruta | Origen | Nombre |
|---|---|---|---|
| GET | `/api/ver/` | `VerArticulos` | `articulos` |
| GET/POST | `/api/crear-articulos/` | `ArticuloListCreateAPIView` | `articulos-create_api` |
| PUT/PATCH/DELETE/GET | `/api/editar-articulos/<pk>/` | `ArticuloDetailGenericAPIView` | `articulos-detail_api` |
| DELETE | `/api/borrar-articulos/<pk>/` | `BorrarArticulo` | `borrar-articulos-api` |

## 11. Convenciones y patrones a replicar

1. **Proyecto en `src/`**, con el paquete de configuración llamado `settings/`.
2. **App de negocio** dentro de `src/` registrada tal cual en `INSTALLED_APPS` (sin prefijo de ruta).
3. **Separación de archivos por responsabilidad:** `models`, `serializers`, `api_views`, `views`, `routers`, `urls`, `permissions`.
4. **`api_views.py`** para `ViewSet` + APIs; **`views.py`** para vistas genéricas/FBV y documentación de patrones.
5. **Serializers duales:** público (anidado, read-only) vs. escritura (FK plana).
6. **`get_serializer_class()`** cambia según el método HTTP (`GET` → público).
7. **`queryset`** siempre con `.select_related("proveedor")` para optimizar la FK.
8. **Respuestas consistentes** con `{"mensaje": ..., "data": ...}`.
9. **Autenticación JWT** por defecto (`JWTAuthentication`) + `SessionAuthentication`.
10. **Permiso base** `IsAuthenticatedOrReadOnly` en las vistas.
11. **Router `DefaultRouter`** en `routers.py`, incluido en `urls.py` con `include(router.urls)`.
12. **Prefijo global `/api/`** definido en `settings/urls.py`.
